# 烟雨行记 · 渡口失印

原创国风探案网页 Demo。三个可切换的 SVG 场景、六条物证和证言、三步证据推理、完整案件结局。支持浏览器本地存档、提示、可开关合成雨声、手机布局与键盘操作。

## 运行

在此目录运行 `node server.cjs`，浏览器打开 http://127.0.0.1:4173 。也可直接打开 dist/index.html。静态资源位于 dist，可部署到静态网站服务。字体联网加载失败时使用系统宋体，不影响游戏。

## 范围

这是点击探索的玩法原型，预计 5–10 分钟。场景、人物和案件均为本 Demo 原创，不含《山河旅探》原作素材。分享链接未能读取，未采用其中的具体设定。没有自由行走、人物配音或复杂背包组合。

## 通关验证

调查每个地点的两个光点，打开案卷可重复查看线索；线索未齐时不能提交推理。正确判断依次为渡船封绳、陆掌柜、断口相合的蓝布与朱蜡。错误判断会给出对应解释，正确判断进入结案。刷新保留进度；重新开始需再次确认。
